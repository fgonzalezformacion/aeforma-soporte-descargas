# Soporte remoto Aeforma · Descargas

Distribución de la aplicación oficial RustDesk con la configuración pública del servicio de asistencia de Aeforma. Guía para clientes: https://soporte.aikot.es.

Los ejecutables conservan los bytes originales de RustDesk. No son una aplicación recompilada ni cambian la marca que muestra RustDesk.

## Windows

Elegir el EXE x64 o ARM64 de la publicación. El nombre largo incluye la configuración pública del servidor: **no renombrarlo**. Abrirlo y seleccionar en Ajustes → Seguridad la aprobación mediante clic. Comunicar el ID al técnico y aceptar la solicitud acordada, sin dictar contraseña.

Si ya existe una instalación o servicio RustDesk de otra empresa, consultar antes de cambiar ajustes. La configuración del servidor no concede acceso automático ni selecciona por sí sola la aprobación mediante clic.

## Mac

Elegir el ZIP Apple Silicon o Intel. Contiene el DMG oficial, instrucciones y el archivo de configuración para importar una vez. Instalar RustDesk en Aplicaciones, importar los ajustes, seleccionar aprobación mediante clic y conceder los permisos de pantalla y accesibilidad que pida macOS. El ZIP no configura automáticamente el Mac.

## Procedencia, código fuente y licencia

RustDesk es un proyecto de sus autores originales y se distribuye bajo GNU AGPL v3 según su licencia. Se conserva una copia de la licencia original en `RUSTDESK-LICENCE.txt`.

- Binarios oficiales y publicación original: https://github.com/rustdesk/rustdesk/releases/tag/1.5.0
- Código fuente y archivos de construcción de la versión original, sin cambios de Aeforma: https://github.com/rustdesk/rustdesk/tree/1.5.0
- Archivo fuente: https://github.com/rustdesk/rustdesk/archive/refs/tags/1.5.0.tar.gz
- Manifiesto y SHA256 de las descargas disponibles como archivos de la publicación.

Este repositorio contiene exclusivamente descargas y documentación pública de incorporación. No contiene configuración privada del servidor, contraseñas, claves privadas ni datos de clientes.
